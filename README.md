# Node.js Authentication 🚀

This repository is a learning project where I explored **authentication** and related backend concepts using **Node.js**, **Express**, and **MongoDB**.  
It covers user login/signup, role-based authentication, pagination, and media file handling with **Cloudinary**.

---

## 📌 Features
- **Authentication (Login & Signup)** using `bcryptjs` and `jsonwebtoken`
- **Role-based authentication** (e.g., Admin vs User access control)
- **Pagination with MongoDB** for efficient data handling
- **Media file uploads** using `multer` and storage with **Cloudinary**
- Environment variable management with `dotenv`

---

## 🛠️ Tech Stack
- **Node.js** (runtime)
- **Express.js** (web framework)
- **MongoDB + Mongoose** (database & ODM)
- **bcryptjs** (password hashing)
- **jsonwebtoken** (JWT authentication)
- **multer** (file upload middleware)
- **Cloudinary** (media storage)
